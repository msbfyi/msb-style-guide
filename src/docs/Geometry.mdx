# Geometry

The chamfer replaces the capsule. A clipped corner reads as
constructed; a rounded one reads as soft — this system is the former.

## The keyline

Every chamfered shape carries a 1.5px keyline — drawn as an inverted
(evenodd) clip-path on a second layer, not a CSS `border` (a real
border can't follow a clip-path corner). See `chamferHost` /
`chamferRules()` in `src/internal/chamfer.ts` for the implementation
every component shares.

## Retired

`--pill` (999px fully-rounded) is kept in the token sheet for legacy
reference only — new work uses the chamfer, not the capsule.
