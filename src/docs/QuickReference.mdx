# Quick Reference

The whole system compressed into one decision: what is this situation
asking of me?

| Situation | Wear |
|---|---|
| First impression / new business | 🟢 Energy — green |
| Authority / own the room | 🔵 Dramatic — cobalt |
| Approachable / sales call | 🟠 Essence — butterscotch |
| Difficult conversation | 🔵 Tranquil — teal |
| Date night / high energy | 🔴 Romantic — red |
| Formal / black tie | ⚫ 1st Base — midnight navy |
| Casual / summer | ⚪ 3rd Base — optic white |
| **Always** | **Contrast. Never blend.** |
