# The Palette

Five accent colors, each with a role — not interchangeable, not
decorative. `--essence`, `--romantic`, `--energy`, `--tranquil`,
`--dramatic`.

## Usage

- **Energy** carries links and "trust" moments — first impressions, new
  business.
- **Romantic** is the vitality color — hover states, "live" status,
  date-night energy. Never pair it directly on `--dramatic` navy (see
  the Light & Dark doc, rule ii).
- **Dramatic** is reserved for fixed color plates (the dispatch plate)
  and "own the room" authority moments — it does not become a
  background tint elsewhere.
- **Tranquil** reads as calm/difficult-conversation register — used
  sparingly.
- **Essence** is the approachable warm neutral-adjacent accent — kicker
  text on dark plates, default badge fill.
