# Vital Spring

A style system for msb.fyi — five accent colors, three neutrals, two
metals, a chamfered corner in place of a rounded one, and one governing
rule: **always contrast, never blend.**

This is the web-component implementation of that system. Every piece
under **Components** in the sidebar is a real, installable
`@msbfyi/style-guide` custom element; everything else in this **Docs**
section is the reference material behind them — palette, type,
patterns, geometry, theming rules, and the source mood board.

## Source

**Color Your Style** — a styling session with David Zyla, October 2022. Archetype: _Vital Spring_. Palette, patterns, and finishing notes
transcribed from the session report, then translated into a design
system almost unchanged: flat fields, hard boundaries, geometric
repeats with an end point, chamfered corners and circle geometry, no
gradients.

Reference: [davidzyla.com — The Color of
Style](https://davidzyla.com/the-color-of-style/)

## Governing rule

> Always contrast. Never blend.
