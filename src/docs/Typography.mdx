## Roles

- **Krona One** — headlines, the lockup wordmark, display numerals.
  Never body copy; it doesn't have the weight range for it.
- **DM Sans** — everything a reader actually reads: body text,
  card copy, entry titles.
- **Barlow Condensed** (uppercase, tracked out) — labels, kickers, nav
  links, button text, badges. Always uppercase, always tracked.
- **JetBrains Mono** — dates, code, the token sheet, anything that
  should read as "data" rather than "voice."
